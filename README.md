# Django Blog Application

A feature-rich, portfolio-ready blog web application built with Python and Django.

## 🚀 Features
- **User Authentication:** Secure registration, login, and logout functionality with custom flash messages.
- **CRUD Operations:** Authenticated users can create, read, update, and delete their own blog posts.
- **Image Handling:** Support for image uploads using Python's `Pillow` library and configured media storage.
- **Responsive Views:** Dedicated home feed, user dashboard ("My Posts"), and author-specific post filtering.

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Database:** SQLite
- **Image Processing:** Pillow
- **Frontend:** HTML5, CSS3
